# Notes Application API

Это RESTful API для приложения заметок, построенное на FastAPI. Оно поддерживает регистрацию пользователей, аутентификацию через JWT и полный цикл CRUD операций для заметок.
Технологии

    FastAPI — веб-фреймворк.

    SQLAlchemy (Async) — ORM для работы с базой данных.

    Pydantic — валидация данных.

    OAuth2 + JWT — безопасность и авторизация.

## Конечные точки (Endpoints)
####  Аутентификация и Пользователи (/v1/users)
| Метод | Путь | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `POST` | `/login` | Вход и получение токена доступа | Публичный |
| `POST` | `/register` | Регистрация нового пользователя | Публичный |
| `GET` | `/` | Получение списка всех пользователей | Авторизован |
| `GET` | `/me` | Просмотр профиля текущего пользователя | Авторизован |
| `PUT` | `/me` | Обновление данных своего профиля | Авторизован |
| `DELETE` | `/me` | Удаление своего аккаунта | Авторизован |
| `GET` | `/{user_id}` | Получение информации о пользователе по ID | Авторизован |
####  Заметки (/v1/notes)
| Метод | Путь | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `GET` | `/` | Получение всех заметок | Авторизован |
| `POST` | `/` | Создание новой заметки (автор — текущий юзер) | Авторизован |
| `GET` | `/{note_id}` | Получение конкретной заметки по ID | Авторизован |
| `PUT` | `/{note_id}` | Обновление заметки (только для автора) | Авторизован |
| `DELETE` | `/{note_id}` | Удаление заметки (только для автора) | Авторизован |
| `GET` | `/by_author/{author_id}` | Получение всех заметок конкретного автора | Авторизован |
## Схемы данных (Schemas)
Пользователь (User)
```
User_Registration: name, email, password (мин. 8 символов).
User_Read: id, name, email.
User_Login: email, password.
User_Update: name (опц.), email (опц.).
```

Заметка (Note)
```
Note_Create: title, content.
Note_Read: id, author_id, title, content.
Note_Update: title (опц.), content (опц.).
```

Токен (Token)
```
Token: access_token, token_type (default: "bearer").
```

## Безопасность

Для доступа к защищенным маршрутам необходимо передавать JWT токен в заголовке запроса:
`Authorization: Bearer <your_token>`
